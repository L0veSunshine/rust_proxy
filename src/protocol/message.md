# Protocol frame definition

## Control Message

### Client Hello

```text
+------------------+------+------+------+---------------------------+---------+---------------------------+
|    User Token    | Ver  | Type | Cmd  |      Target Address       | Pad Len |          Padding          |
|  (UUID 128-bit)  | 0x01 | 0x01 | 0x01 |     (ATYP + Addr + Port)  |  (2B)   |       (0-65536 Bytes)     |
+------------------+------+------+------+---------------------------+---------+---------------------------+
```

- Token: UUID
- Ver: 0x01
- Type: 0x01 (保留字段，目前固定 0x01，未来可用作扩展)
- Cmd: 
  - 0x01 TCP Connect 
  - 0x02 UDP Associate
- Target Address: 见下。
- Pad Len: 大端 u16，取值服从 N(360, 60²) 并截断到 [16, 600]。
  上限保证整个握手包（最长地址时）不超过服务端 1024 字节的握手缓冲区。
- Padding: Pad Len 个字节（在 TLS 内传输，内容为 0）。

### Server Response

```text
+----------+--------+-----------+
|  Length  | Status |  Padding  |
|   (1B)   |  (1B)  |    N-1    |
+----------+--------+-----------+
```
- Length: Status + Padding 的总长度，至少为 1；Padding 长度服从 N(150, 25²) 并截断到 [0, 254]。
- Status（仅在服务端完成上游建连 / UDP 绑定后返回）：
  - 0x01: 成功。上游连接已建立（或 UDP 套接字已绑定），TCP 后续流量直接转发，UDP 使用 [UDP帧格式](#udp)。
  - 0x02: 一般失败（上游建连或绑定失败）。
  - 0x03: 目标主机或网络不可达（含 DNS 解析无结果）。
  - 0x04: 目标拒绝连接（Connection Refused）。
  - 0x05: 连接目标或解析域名超时。

客户端支持真正的 0-RTT 发送：可在发出 `Client Hello` 的同时直接携带或连续发送应用层上行首包，并在下行流首部读取 `Server Response`。
鉴权失败、重放等情况服务端不会返回错误码，而是把流量回落到本地 Web 服务，以对抗主动探测。

## Data Transfer

### UDP
```text
+-----------+---------------------------+-------------------------------+
| Body Len  |      Target Address       |            Payload            |
| (VarInt)  |        (Variable)         |           (N Bytes)           |
+-----------+---------------------------+-------------------------------+
      ^                   ^
      |                   |
      |                   +---> Target Address
      +---> 后续数据的总长度 (Addr + Payload)，最大 65535
```

Body Len 使用 1~3 字节的变长编码：

| 首字节前缀 | 长度 | 取值范围 | 编码 |
|---|---|---|---|
| `0xxxxxxx` | 1B | 0 ~ 127 | 低 7 位即长度 |
| `10xxxxxx` | 2B | 128 ~ 16383 | 首字节低 6 位为高位，第二字节为低 8 位 |
| `11000000` | 3B | 16384 ~ 65535 | 后两字节为大端 u16 |

## Target Address

### Ipv4

```text
+------+-----------------------+-----------------------+
| ATYP |       IPv4 Addr       |         Port          |
| 0x01 |       (4 Bytes)       |       (2 Bytes)       |
+------+-----------------------+-----------------------+
    |              |                        |
    |              |                        +---> Big Endian (e.g. 443 = 0x01 0xBB)
    |              +---> e.g. 192.168.1.1 = C0 A8 01 01
    +---> Type 1
```

### Domain

```text
+------+------+-------------------------------+-----------------------+
| ATYP | Len  |            Domain             |         Port          |
| 0x03 | (1B) |          (Len Bytes)          |       (2 Bytes)       |
+------+------+-------------------------------+-----------------------+
   |      |                  |                            |
   |      |                  |                            +---> 端口
   |      |                  +---> "google.com" (ASCII/UTF8)
   |      +---> 域名长度 (e.g. 10)
   +---> Type 3
```

### Ipv6

```text
+------+---------------------------------------------------------------+-----------------------+
| ATYP |                           IPv6 Addr                           |         Port          |
| 0x04 |                          (16 Bytes)                           |       (2 Bytes)       |
+------+---------------------------------------------------------------+-----------------------+
```
